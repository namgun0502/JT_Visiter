# 방문자 관리대장 출력 및 DB 추출 기능 계획서

보내주신 사진(환경설비 관리대장)과 같이, 결재판과 깔끔한 표 형식으로 **'방문자 관리대장'**을 화면에 띄우고, 이를 PDF로 인쇄하거나 엑셀(CSV) DB로 다운로드할 수 있는 기능을 추가합니다.

## Proposed Changes

### 1. `index.html` (레이아웃 및 UI 추가)
* **사이드바 메뉴 추가:** 좌측 메뉴에 `📄 대장 인쇄` 탭을 신설합니다.
* **관리대장 화면(패널):**
  * 날짜를 검색할 수 있는 **기간 필터** (시작일 ~ 종료일)를 상단에 배치합니다.
  * 상단 우측에 **[PDF 인쇄]**, **[엑셀(CSV) 다운로드]** 버튼을 만듭니다.
  * 하단에는 사진과 유사한 형태의 A4 비율 **'방문자 출입 관리대장'** 표 영역을 만듭니다.
* **출력용 CSS (`@media print`):**
  * 인쇄 버튼을 누르면 브라우저 인쇄 창이 뜹니다.
  * 인쇄될 때는 사이드바나 버튼들이 모두 숨겨지고, 오직 결재판(작성/검토/승인)과 대장 표, 그리고 하단 문서번호 양식만 깔끔하게 A4 용지에 꽉 차게 인쇄되도록 디자인합니다.

### 2. `app.js` (데이터 로딩 및 인쇄/다운로드 로직)
* **`loadLedger(startDate, endDate)`:** 선택한 기간에 해당하는 보관함(적합/부적합 처리 완료) 데이터를 불러와 표에 채워 넣습니다.
  * **표 컬럼(예상):** No, 방문일시, 소속/성명, 안내자, 목적, 적합 여부(안내자 평가), 결재 상태(최종 결재), 비고
* **`printLedger()`:** 인쇄 전 화면을 최적화하고 `window.print()`를 호출하여 PDF로 저장하거나 프린터로 출력할 수 있게 합니다.
* **`exportToCSV()`:** 표에 있는 데이터를 CSV 형식(DB 형태)으로 변환하여 사용자의 PC에 다운로드되도록 만듭니다.
