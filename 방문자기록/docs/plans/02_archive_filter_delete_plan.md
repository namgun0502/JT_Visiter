# 보관함 필터링 및 삭제 기능 추가 계획

보관함 탭에서 방문자 기록을 원하는 상태(전체/적합/부적합)로 필터링해서 볼 수 있는 기능과, 불필요한 기록을 영구 삭제할 수 있는 기능을 추가합니다.

## User Review Required

> [!IMPORTANT]
> **권한 설정 확인**
> 1. **삭제 권한:** 아무나 방문자 기록을 지우면 안 되므로, **'승인자' 또는 '안내자+승인자' 권한을 가진 사람만 삭제 버튼을 누를 수 있도록** 제한하려고 합니다. 괜찮으신가요?
> 2. **삭제 알림:** 삭제 버튼을 누르면 "정말 삭제하시겠습니까? 복구할 수 없습니다." 라는 확인 알림(confirm)을 띄워 실수를 방지하도록 하겠습니다.

## Proposed Changes

### `index.html`
- **[MODIFY]** `tab-archive` 패널 상단에 필터 버튼 3개(`전체`, `적합`, `부적합`) 렌더링.

### `app.js`
- **[MODIFY]** `loadArchiveApprovals(filter)` 함수 수정:
  - 인자로 넘어온 필터값에 따라 Supabase 데이터베이스에서 '승인' 데이터만 가져오거나 '반려' 데이터만 가져오도록 쿼리 수정.
  - 화면 상단 필터 버튼의 활성화(active) 디자인 토글 로직 추가.
  - 보관함 카드 우측 또는 하단에 **[🗑️ 삭제]** 버튼 추가 (결재 권한이 있는 사용자에게만 노출).
- **[MODIFY]** `deleteArchiveRecord(id)` 함수 추가:
  - 사용자에게 `confirm` 알림창 표시 후 `db.from('visitors').delete()` 호출.
  - 삭제 성공 시 현재 선택된 필터 상태를 유지하며 목록 새로고침.

## Verification Plan

### Manual Verification
1. 보관함에 들어가서 '전체 / 적합 / 부적합' 탭을 각각 클릭했을 때 목록이 알맞게 필터링되는지 확인합니다.
2. 승인자 권한이 있는 계정으로 로그인한 상태에서 카드의 '삭제' 버튼을 눌러 정상적으로 데이터가 지워지는지 확인합니다.
3. 승인 권한이 없는 계정이거나 비로그인 상태일 때는 '삭제' 버튼이 보이지 않거나 비활성화되어 있는지 확인합니다.
