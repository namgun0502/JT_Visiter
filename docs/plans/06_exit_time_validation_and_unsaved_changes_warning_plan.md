# 퇴실 시간 유효성 검증 및 미저장 변경사항 경고 기능 구현 계획서

## 1. 개요
1. **퇴실 일시 유효성 검증**:
   - 퇴실일(exit_date)은 항상 입실일(isit_date)과 동일하도록 설정.
   - 퇴실 시간(exit_time)은 입실 시간(isit_time)보다 이전 시각(빠른 시각)일 수 없도록 검증 방어 로직 적용.
   - 입실 시간 수정 시에도 기존 퇴실 시간보다 늦은 시간으로 변경되지 않도록 상호 검증.

2. **미저장 수정사항 이탈 방지 경고**:
   - 모달 내에서 입실 일시 또는 퇴실 시간을 입력/수정한 후 저장 버튼을 누르지 않고 모달을 닫으려 할 때, 확인 팝업("저장하지 않은 변경사항이 있습니다. 닫으시겠습니까?") 표시.

---

## 2. 세부 구현 내용
1. **시간 유효성 검증 로직 (alidateVisitExitTimes)**:
   - exitTime <= visitTime 인 경우 에러 토스트 안내: ⚠️ 퇴실 시각은 입실 시각보다 늦어야 합니다.
   - quickExitRecord, saveDetailExitTime, saveDetailVisitDateTime 등에 공통 적용.

2. **미저장 변경 감지 (Dirty Check)**:
   - 모달 열릴 때 초기 입실일자/시간, 퇴실시간을 기록 (initialModalState).
   - 모달 닫기 시도 (closeApprovalModal) 시 현재 입력값과 초기값을 비교.
   - 변경 사항이 있을 경우 커스텀 컨펌 모달로 사용자에게 확인 후 닫기 처리.
