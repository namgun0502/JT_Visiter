# 16. 익일 미퇴실 알림 발송 시간 기준(익일 오전 9시 이후) 적용 계획서

## 1. 개요
퇴실 미처리 방문자에 대한 이메일 알림 및 팝업 안내가 날짜가 바뀌자마자(자정) 무분별하게 발송되지 않고, 업무 시작 시간인 **다음 날 오전 9시 이후(09:00~)**에만 발송되도록 제한합니다.

## 2. 세부 로직
1. checkUnreturnedVisitors 실행 시 현재 시각의 getHours() 확인
2. 현재 시각이 **오전 9시 미만(00:00 ~ 08:59)**일 경우:
   - 아직 이메일 알림을 발송하지 않고 대기 (익일 09시 정규 출근 시간 이후 발송되도록 제한)
3. 현재 시각이 **오전 9시 이상(09:00 이후)**일 경우:
   - 미퇴실 방문자 조회 및 결재승인자 대상 이메일 알림 발송 실행 (당일 1회 제한 유지)
