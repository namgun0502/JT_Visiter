# 17. 모바일 뱃지 표시 및 이력 관리 테이블 가로 스크롤바(언더바) UI 개선 계획서

## 1. 개요
1. 모바일 하단 네비게이션 바에서 결재승인, 보관함, 휴지통 탭의 숫자 뱃지가 명확하고 깔끔하게 보이도록 CSS 위치 및 디자인을 조정합니다.
2. 이력 관리 테이블에서 모바일/작은 화면 시 오른쪽 내용이 잘려 보이지 않던 문제를 해결하기 위해 눈에 잘 띄는 가로 스크롤바(언더바) 스타일을 적용합니다.

## 2. 작업 내용
1. style.css:
   - @media (max-width: 768px) 내 .nav-btn에 position: relative 보장 및 .nav-badge 위치/스타일(크기, 폰트, 배경) 최적화
   - .table-responsive에 커스텀 가로 스크롤바(Webkit scrollbar) 스타일 적용 (두께, 트랙, 핸들 색상 지정)
   - .data-table의 최소 너비를 설정하여 모바일에서도 모든 컬럼(시간, 작업, 대상 방문자, 작업자, 상세 내용)이 가로 스크롤로 온전히 보이도록 개선
