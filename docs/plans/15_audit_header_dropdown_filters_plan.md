# 15. 전체 이력 관리 테이블 컬럼 헤더 드롭다운 필터 기능 구현 계획서

## 1. 개요
전체 이력 관리 테이블의 각 컬럼 제목(작업, 대상 방문자, 작업자, 상세 내용)을 클릭하면 엑셀처럼 선택 가능한 항목 팝업/드롭다운 목록이 열리고, 원하는 항목을 선택하여 즉시 필터링할 수 있도록 구현합니다.

## 2. 세부 기능
1. **컬럼 헤더 드롭다운**:
   - **작업 (Action)**: 전체, 등록, 승인, 반려, 퇴실, 삭제됨, 영구삭제, 복구됨, 수정됨 목록 팝업
   - **대상 방문자 (Visitor)**: 현재 이력에 존재하는 방문자 목록 검색 및 선택 팝업
   - **작업자 (Actor)**: 현재 이력에 존재하는 작업자(직원) 목록 팝업
   - **상세 내용 (Remarks)**: 검색어 입력 또는 주요 키워드 선택 팝업
2. **UI 및 상호작용**:
   - 헤더에 필터 아이콘(▼) 표시
   - 헤더 클릭 시 팝오버 드롭다운 메뉴 오픈 (외부 클릭 시 자동 닫힘)
   - 선택된 필터가 있을 경우 헤더 강조(색상 변경 및 표시)
