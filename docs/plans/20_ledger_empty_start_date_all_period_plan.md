# 20. 관리대장 출력 시작일 기본값 비우기 및 전체 기간 조회 지원 계획서

## 1. 개요
관리대장 출력 탭 진입 시 시작일(ledger-start-date)을 당월 1일로 강제 설정하지 않고 빈 값으로 두어, 시작일부터 종료일까지 전체 기간(시스템 내 모든 결재 완료 기록)을 바로 한눈에 조회할 수 있도록 변경합니다.

## 2. 작업 내용
1. pp.js의 switchTab('ledger') 시:
   - ledger-start-date를 빈 문자열('')로 설정
   - ledger-end-date는 오늘 날짜로 기본 설정
2. loadLedger() 함수 조건 수정:
   - 시작일이 비어있으면 gte 조건을 걸지 않고 전체 과거 기록부터 조회
   - 종료일이 지정되어 있으면 해당 종료일까지 조회
   - 시작일/종료일이 모두 비어있어도 전체 데이터 정상 조회
3. exportToCSV() 함수 파일명 처리:
   - 시작일이 비어있으면 전체_.csv 형태로 안전하게 다운로드되도록 개선
