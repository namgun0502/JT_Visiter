# 12. 익일 미퇴실 방문자 결재승인자 이메일 알림 구현 계획서

## 1. 개요
방문일자로부터 하루 이상 경과했으나 퇴실 처리(exit_time)가 되지 않은 방문자가 발견될 경우, 해당 방문자의 결재승인자에게 미퇴실 경고 이메일을 발송합니다.

## 2. 작업 내용
1. EmailJS 미퇴실 알림용 템플릿 상수(EMAILJS_UNRETURNED_TEMPLATE_ID) 추가 또는 기존 결재요청 템플릿 연동
2. checkUnreturnedVisitors 실행 시 하루 1회에 한해 미퇴실 방문자의 지정 결재승인자에게 이메일 알림 전송 로직 구현 (중복 발송 방지: localStorage 활용)
3. 미퇴실 알림 이메일 템플릿 구성 및 가이드
