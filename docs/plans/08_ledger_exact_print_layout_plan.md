# 관리대장 인쇄 레이아웃 정밀 수정 계획서 (상단 우측 단일화 및 바닥글 최하단 고정)

## 1. 개요
인쇄 출력물에서:
1. 상단 중앙의 브라우저 기본 타이틀을 숨기고, 날짜와 동일한 높이의 **오른쪽 상단에 JT_Visiter가 딱 1개만** 오도록 처리.
2. 페이지 중간에 떠 있던 **(주)제니트리 1/1 영역을 A4 용지의 최하단(바닥글 위치 우측)**으로 이동 고정.

---

## 2. 세부 변경 사항
1. **인쇄 트리거 헬퍼 함수 printLedger() 구현**:
   - 인쇄 시 document.title = ' '로 일시 변경하여 브라우저 기본 중앙 타이틀 중복 방지.
   - 인쇄 후 원래 제목(JT_Visiter)으로 자동 복구.
2. **상단 우측 헤더 바 (print-top-header)**:
   - 날짜와 수평을 맞추는 최상단 우측에 JT_Visiter 단일 배치.
3. **하단 푸터 바닥글 고정 (position: absolute; bottom: 0; right: 0;)**:
   - 인쇄 시 #printable-ledger를 페이지 전체 높이로 확장하고, 푸터를 A4 용지 맨 아래쪽 우측 끝에 배치.
