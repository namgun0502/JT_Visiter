# 적합/부적합 보관함 탭 추가 및 상태 수정 기능

현재 결재 대기 중인 방문자만 보이는 구조에서, **이미 결재가 완료된(적합/부적합) 기록들을 보관하고 관리하는 별도의 탭**을 만듭니다. 또한 실수로 잘못 결재했거나 상황이 바뀐 경우, 보관함에서 결재 상태를 다시 수정할 수 있는 기능을 추가합니다.

## User Review Required

> [!IMPORTANT]
> - **보관함 접근 권한:** 적합/부적합 보관함도 기존 결재 탭처럼 누구나 목록과 상세 내용을 볼 수는 있지만, **"결재 상태 수정" 버튼은 승인자(또는 안내자+승인자) 권한을 가진 사람만** 누를 수 있도록 설정하려고 합니다. 괜찮으신가요?
> - **결재 완료 후 이동:** 대기열에서 적합/부적합 버튼을 누르면 기록이 대기열에서 즉시 사라지고 보관함 탭으로 자동으로 넘어가게 됩니다.

## Proposed Changes

### `index.html`
- **[MODIFY]** 사이드바에 `적합/부적합 보관함` 탭 버튼 추가 (결재 승인 탭 아래).
- **[MODIFY]** 메인 영역에 보관함 전용 화면(목록 UI) 추가.

### `app.js`
- **[MODIFY]** `switchTab` 함수에 보관함(`archive`) 탭 관련 텍스트 및 데이터 로드 로직 추가.
- **[MODIFY]** `loadArchiveApprovals()` 함수 신규 생성: `approval_status`가 '승인' 또는 '반려'인 방문자 목록을 불러와 렌더링.
- **[MODIFY]** 보관함의 상세 모달 혹은 카드 목록에 **"결재 상태 변경"** 버튼을 추가하고, 승인자 권한이 있는 경우에만 표시되도록 처리.
- **[MODIFY]** 상태 변경 함수(`toggleApprovalStatus`) 추가: 적합을 부적합으로, 부적합을 적합으로 바꿀 수 있게 하고, 변경 시 데이터베이스 업데이트 및 화면 새로고침 수행.

## Verification Plan

### Manual Verification
1. 결재 승인 대기열에서 임의의 방문자를 '적합' 처리해봅니다.
2. 해당 방문자가 대기열에서 사라지고, '적합/부적합 보관함' 탭에 나타나는지 확인합니다.
3. 승인자 권한으로 로그인한 상태에서 보관함의 해당 방문자의 '상태 수정' 버튼을 눌러 부적합으로 잘 변경되는지 확인합니다.
4. 비로그인 혹은 권한이 없는 직원이 보관함을 볼 때 '상태 수정' 버튼이 비활성화되거나 보이지 않는지 확인합니다.
