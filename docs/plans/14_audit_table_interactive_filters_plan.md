# 14. 전체 이력 관리 테이블 셀 클릭 필터링 및 필터 뱃지 기능 구현 계획서

## 1. 개요
전체 이력 관리 테이블에서 각 항목(작업, 대상 방문자, 작업자, 상세 내용)을 클릭하면 해당 조건으로 즉시 필터링되고, 상단에 활성화된 필터 뱃지가 표시되어 손쉽게 해제할 수 있도록 합니다.

## 2. 세부 기능
1. **클릭 필터링 지원 항목**:
   - **작업 (Action)**: 클릭 시 해당 작업(예: APPROVED, DELETED 등)만 필터링
   - **대상 방문자 (Visitor)**: 클릭 시 해당 방문자 ID 또는 방문자 이름으로 필터링
   - **작업자 (Actor)**: 클릭 시 해당 작업자명으로 필터링
   - **상세 내용 (Remarks)**: 클릭 시 해당 상세 내용 키워드로 필터링
2. **UI 및 상호작용 개선**:
   - 각 셀에 마우스 호버 시 포인터 커서(pointer)와 밑줄/강조 효과 제공 (클릭 가능함을 시각적으로 안내)
   - 상단에 현재 적용된 필터 태그(뱃지) 영역 추가 (예: 작업: 승인 ✕, 작업자: 형남건 ✕)
   - 필터 태그의 ✕ 또는 필터 초기화 버튼 클릭 시 필터 즉시 해제
